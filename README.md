## 👋 About Me

I'm an **Electronics and Communication Engineering (ECE) student** at JSS Science and Technology University (formerly SJCE), Mysuru, exploring the intersection of **software development, AI, and electronics**.

- 🤖 Building and learning about **Retrieval-Augmented Generation (RAG)** and AI-powered applications.
- 💻 Strengthening programming fundamentals and problem-solving through hands-on practice.
- ⚡ Exploring signal processing, MATLAB/Octave, and electronics simulation.
- 🧰 Learning to write maintainable code, document projects, and use Git/GitHub effectively.
- 🎯 Preparing for opportunities in **software development and core ECE**.
